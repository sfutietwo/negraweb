📋 Quote Form Website — Setup Guide

Everything you need to get this website live and receiving customer requests by email.

What you're getting: A ready-made website with a customer quote/request form. When someone submits it, the details are emailed straight to your inbox — no dashboard, no login, no database to manage. You just need two free accounts to switch it on.

Part 2 — Create your two free accounts

You need two free accounts. Neither needs a credit card.

1Create a free Supabase account

Go to supabase.com → Sign up (free) → Create a new project. Pick any name and password, and choose the region closest to your customers.

Wait about 2 minutes for the project to finish setting up.

2Deploy the email function (no coding needed)

In your new Supabase project, go to the Edge Functions section in the left menu → Deploy a new function → give it the name send-quote-request.

Open send-quote-request-function.ts from this folder in a text editor, select all the text, copy it, and paste it into the code box Supabase gives you. Click Deploy.

Once deployed, click on the function and copy its URL — it will look like:

https://YOUR-PROJECT-ID.supabase.co/functions/v1/send-quote-request

Keep this URL handy — you'll need it in Part 3.

3Create a free Brevo account (this is what sends the emails)

Go to brevo.com → Sign up (free plan — 300 emails/day, plenty for this). Use the same email address you want notifications sent from.

Once logged in, go to your profile → Settings → SMTP & API → API Keys tab → Generate a new API key. Name it anything, then copy the key (it starts with xkeysib-).

Because you signed up with your own email, that email is automatically an approved sender — no domain purchase or verification needed.

Part 3 — Connect the website to your email

4Add your secrets in Supabase

In Supabase, go to Edge Functions → click on send-quote-request → Secrets tab → add these four:

Secret nameValue
BREVO_API_KEYThe API key you copied from Brevo
SENDER_EMAILThe email address you signed up to Brevo with
NOTIFY_TO_EMAILNot needed any more — requests are always sent to sfutie4@gmail.com (set in the function code).
BUSINESS_NAMEYour business name, e.g. Joe's Plumbing

5Edit saw-config.js

Open saw-config.js in any plain text editor (Notepad, TextEdit, VS Code — anything works). Replace the placeholder with the function URL you copied in Step 2:

window.SAW_SUPABASE_CONFIG = { sendUrl: "https://YOUR-PROJECT-ID.supabase.co/functions/v1/send-quote-request" };

Save the file. That's the only file you ever need to edit.

Part 4 — Put the website online

Since you already have a website or domain, pick whichever matches your situation:

Option A — You have web hosting with file upload (cPanel, FTP, etc.)

Upload every file in this folder (except send-quote-request-function.ts and this guide) into your website's folder — usually called public_html or www. If you want it as its own page rather than replacing your homepage, put the files in a subfolder like /quote/ and it'll appear at yourdomain.com/quote/.

Option B — You use WordPress, Wix, Squarespace or similar

These platforms don't let you upload raw HTML files directly. The easiest fix is a separate free page:

  • Go to app.netlify.com/drop (no account needed for a quick one-off, free account recommended for a permanent link)
  • Drag this whole folder onto the page — you'll get a live link instantly
  • Add a "Get a Quote" button on your existing website that links to that new page

Option C — You don't have hosting yet

Netlify (free) is the simplest: create a free account at netlify.com, drag this folder onto their dashboard, and you'll get a free yourname.netlify.app address instantly. You can connect your own domain to it later, still free.

Part 5 — Customise it for your business

Open index.html in a text editor and use Find & Replace for these common things:

  • Business name and logo (search for the current business name, replace throughout)
  • Phone number and email address in the footer/contact section
  • Service area / location text
  • Colours — search for --yellow: near the top of the file to change the accent colour
Keep a backup copy of the original files before editing, in case you want to start over.

Part 6 — Test it

  • Open your live site in a browser
  • Fill out the quote form with test details and submit
  • Check the sfutie4@gmail.com inbox — the request should arrive within a few seconds
  • Check your spam folder the first time, just in case

Troubleshooting

ProblemLikely fix
Nothing arrives by emailDouble-check all 4 secrets are saved correctly in Supabase, with no extra spaces
Form shows "Could not send"Check saw-config.js has the correct function URL, including https://
Emails go to spamNormal at first with a free Brevo sender — ask the recipient to mark it "not spam" once
Free tier limits: Brevo's free plan allows 300 emails/day — more than enough for most small businesses. Supabase's free tier pauses a project after a week of no activity; if that happens, just log in to Supabase and click "Restore" — takes about a minute and nothing is lost.
